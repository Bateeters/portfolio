## Project Structure

```
portfolio/
├── index.html          # Single-page layout with section anchors
├── css/
│   ├── base.css        # Design tokens, typography, global styles
│   ├── layout.css      # Section layouts and structural styles
│   └── cards.css       # Component styles (project cards, skill cards, etc.)
├── js/
│   ├── projects-tabs.js    # Project card rendering + modal population
│   ├── skills-section.js   # Skills grid rendering
│   ├── experience-section.js # Experience timeline rendering
│   ├── hero-section.js     # Hero/about section logic
│   └── nav-scrollspy.js    # Active nav link tracking on scroll
└── data/
    ├── projects.js     # Project data (descriptions, tech, links)
    ├── skills.js       # Skill categories and currently-exploring list
    └── experience.js   # Work history entries
```

All content is data-driven — updating projects, skills, or experience only requires editing the files in `data/`.
